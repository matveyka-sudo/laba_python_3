# Лабораторная работа номер 3 по предмету: "Программирование на языке python"

## Введение
Цель работы: Научиться реализовывать пользовательские коллекции и ленивую обработку
задач.    
Постановка задачи: Разработать очередь задач (TaskQueue), поддерживающую итерацию,
фильтрацию и потоковую обработку задач.

## Структура проекта
В папке src лежат основные файлы, которые содержат в себе:  
1-"12.txt", содержит данные для генерации задач  
2-"init.py"  
3-"contract.py", содержит класс, имеющий нужный метод для проверки, содержит ли в себе класс метод генерации  
4-"descriptors.py", содержит в себе дескрипторы  
5-"exceptions.py", содержит в себе пользовательские ошибки   
6-"generator_1.py", содержит в себе генератор задач  
7-"generator_2.py", содержит в себе генератор задач  
8-"generator_3.py", содержит в себе генератор задач  
9-"logg.py", содержит в себе настройки для логгирования  
10-"logger.py", сам logger  
11-"main.py", точка входа, содержит в себе демонстрацию работы проекта  
12-"models.py", содержит в себе модель задачи  
13-"proc.py", содержит в себе функцию проверки на наличие метода генерации при помощи isinstance, которая также собирает все задачи в один список  
14-"TaskQueue.py", содержит в себе асинхронную очередь  
15-папка tests, содержит в себе тесты и необходимые для них данные
